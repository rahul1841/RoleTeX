| D-19 | 2026-09-06 | **In-app resume builder** (`backend/app/builder.py` + three routes), so owning a resume no longer requires a document to import or a provider key. ## 5. Deferred / rejected ideas

- **Byte/hash protected-region comparison** (plan §2.2) — superseded by the token-slot model (D-2).
- **Local CLI** (plan Phase 1) — skipped (D-7).
- **Compiling imported user LaTeX directly** — rejected for safety (D-6); `source.tex` retained for possible future exact-layout work under stronger isolation. **Re-examined 2026-09-07 with empirical probes (see §2) and the rejection stands and hardened**: `--untrusted` does not stop arbitrary file reads/writes, so a user template could `\input{/proc/self/environ}` and typeset `MONGODB_URI` + `APP_SECRET_KEY` into a PDF it then downloads. Sanitizing is not viable (blocklist bypass demonstrated; TeX is not parseable without executing it), and `--only-cached` would reject most real templates anyway on missing packages. Preferred paths if fidelity is ever wanted, in order: (1) widen `sanitize_style` into a real bounded theme profile — extract design intent, not code; (2) a hand-authored server-side template gallery the extraction picks from; (3) client-side WASM compile for a "render my original" download, which keeps the blast radius in the author's own browser. Adopting a user's preamble was considered and rejected — it concentrates exactly the dangerous constructs.
- **Public deployment** — rejected until auth + rate limiting exist (rules.md M-3).

## 7. Operational notes

- Dev backend: `uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload`; tests: `.venv/bin/python -m pytest -q`.
- Dev frontend: `cd frontend && npm run dev` → <http://localhost:3000>. `next dev` proxies `/api/*` to the backend so the browser stays on one origin, which is what keeps the HttpOnly cookie and the Origin-equals-host CSRF check working without CORS.
- `LLM_PROVIDER=stub` gives a deterministic offline flow (`backend/app/llm_stub.py`) — output is fixture text, prefixed `[stub]`, *not* genuinely tailored. It is **opt-in**, never a default. (The former `mock` provider was deleted in `cdc1a82`; the stub replaced it on 2026-09-10 to restore offline development and unblock the test suite.)
- Local toolchain via Homebrew: `brew install tectonic poppler`.
- Docker build needs network once (cache pre-warm); runtime is `--only-cached`, so template/package changes require an image rebuild (rules.md M-1).
